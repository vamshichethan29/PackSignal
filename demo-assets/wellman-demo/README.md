# Wellman four-face demo input

## Recommended: automatic four-face path

Create a new review and choose **Photo / video / camera**. Add these files **one
at a time**. Before every upload, set **Face to capture** to the matching face:

1. **Front** → `wellman-label-01-front.jpg`
2. **Back** → `wellman-label-02-back.jpg`
3. **Right side** → `wellman-label-03-right.jpg`
4. **Left side** → `wellman-label-04-left.jpg`

Do not select all four in one file-picker action: a batch is intentionally left
unassigned because the app cannot know which image is which. Do not use the
video or bottom photo in this four-face demo.

After creating the review, open **Sources**:

1. Set **Package type** to **Bottle label**.
2. Choose **Use suggested faces as starting crops**.
3. Tick the confirmation that you inspected the visible artwork crops.
4. Save decisions and recalculate.

Then open **Review → 3D context**. The face buttons show Front, Right side,
Back, and Left side.

Use **India – FSSAI label topics** under Optional settings if you want the
starter checklist in addition to capture and evidence checks.

## Alternative PDF path

`wellman-bottle-four-labelled-faces.pdf` contains the same four cropped faces,
but PDF uploads do not carry face names. Use it only if you want to draw/map
the four face crops yourself in Sources.

`wellman-capture.mp4` is the original supplied video. It can demonstrate frame
extraction, but it is not part of the clean four-face label demo.

No official manufacturer product specification is included. This demo therefore
records review tasks and visible evidence; it does not claim the product label
is compliant. Add an approved product spec separately for exact comparisons.
