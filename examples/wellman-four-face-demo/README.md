# Wellman four-face normal-upload demo

Upload exactly these two files through **New review → PDF / artwork file**:

1. `wellman-four-face-artwork.pdf` as **Artwork**
2. `wellman-product-spec.json` as **Product spec**

The PDF contains the supplied front, back, left and right package photos on one explicitly labelled flat sheet. The product specification declares `bottle_label`, so PackSignal renders the normal generated four-face bottle-label preview from these uploaded files. It is not one of the frozen built-in samples.

The JSON is a demonstration reference transcribed only from visible packaging facts; it is not manufacturer-authoritative or a compliance certification.
